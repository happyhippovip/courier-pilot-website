Konzept / Prototyp

Concept use cases

Target picture for ledger, admission gates, and crash recovery. Not a catalog of finished products. The evidenced path so far is the synthetic controller/worker run in PR #361.

01

Automated Codebase Verification & Reality Audits

Zielbild: catch hallucinated tests, broken imports, or forgotten file updates with an independent check — not a certified auditor product.

  • Repo Reality Check (goal): Inspect public Git trees and report measurable facts; beta offer is separate and unpaid on this site.
  • Regression discipline (goal): Prefer tests that ratchet forward; not claimed as a universal CI product.
  • Receipts (prototype): Aims for hashed audit reports tied to commit SHAs; demonstrated path is the synthetic receipt in PR #361.
02

Multi-Day Unattended Agent Runs

Standard agent CLI tools often stop when a session disconnects. Courier aims to resume from the last verified checkpoint — prototype, not a finished unattended product.

  • Checkpointing (goal): Progress recorded event-by-event in an append-only journal on disk.
  • Supervision (goal): Detect stalled work and resume safely without inventing success.
  • Host capacity (goal): Bound heavy jobs so one machine is not overloaded — not proven for every OS here.
03

Cross-Platform Distributed Execution

Zielbild: route work to capable hosts (e.g. Windows Job Objects). Packaging and clean-machine shipping are not claimed on this page.

  • Capability routing (goal): Dispatch only to hosts that can run the task.
  • Process containment (goal): Prefer exact owned process trees; Windows Job Objects are the intended Windows path.
  • Workspace isolation (goal): Keep task workspaces from corrupting a shared tree — direction, not a shipped matrix.
04

Heavy Media & Asset Generation Pipelines

Zielbild: heavy renders with admission control and integrity checks — concept only; not an evidenced media product run.

  • Admission (goal): One heavy pipeline per host at a time where enforced.
  • Output checks (goal): Reject blank or corrupt outputs before calling work done.
  • Artifact receipts (goal): Checksums and metadata with the result — not a public SLA.

Was belegt ist

Die Seiten zu Anwendungsfällen sind Konzept und Prototyp. Belegt ist ein Controller- und Worker-Lauf mit synthetischem Test-Baustein: harter Abbruch, Neustart, 0 doppelte Aufgaben, nachrechenbarer Beleg, CI 12 von 12. Ein Lauf mit echtem Anbieter ist noch nicht nachgewiesen.

  • Beleg: PR #361
  • CI in diesem Lauf: 12 von 12 grün
  • Grenze: synthetischer Test-Baustein, kein echter Anbieter
