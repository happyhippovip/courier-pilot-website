German Bescheid Deadline Tracker

Calculates strict administrative appeal deadlines (Rechtsbehelfsfristen) under § 41 VwVfG with automated 4-day Bekanntgabe-Fiktion and state holiday shifts.

  • Considers Reformationstag & Easter shifts
  • Enforces 7-day early action target boundary
  • Ziel: keine erfundenen Kalenderdaten
02

Deterministic Spreadsheet Reconciliation

Modifies cell formulas and values in .xlsx workbooks with standard-library precision and independent before/after SHA-256 validation.

  • Atomic in-place mutations without Excel locks
  • Verifiable before/after hash receipts
  • Rollback on untouched cell modification
03

Inbound Triage & Gated Invoice Delivery

Processes incoming customer emails, classifies intent, generates invoices, and blocks external communication until explicit human confirmation.

  • Auto-detects bounces and vacation notices
  • Strict human gate for monetary transactions
  • Ziel: keine ausgehende Mail ohne Freigabe
04

Autonomous Repository Reality Sweep

Performs background codebase integrity audits, monitors git worktrees for orphaned locks, and verifies SHA-256 commit chains without human oversight.

  • Single-writer concurrency lock enforcement
  • Self-healing crash recovery from SQLite WAL
  • Ziel: keine erfundenen Änderungen

Ein Ziel, mehrere Werkzeuge

Courier hält fest, welches Werkzeug welche Aufgabe übernommen hat, und gibt jede Aufgabe nur an einen Bearbeiter (ein Schreiber pro Aufgabe). Fällt ein Werkzeug aus, kann ein anderes am letzten geprüften Stand weitermachen. Stand: Prinzip im Prototyp umgesetzt, Anbindung echter Anbieter in Arbeit.

One goal, many tools: one writer per task, handover at the last verified checkpoint. Prototype; real provider adapters in progress.

Prototype sketch: append-only journal for recoverable continuation — not a finished product claim.

-- Canonical Event Schema (courier_core/journal.py) CREATE TABLE events ( seq INTEGER PRIMARY KEY AUTOINCREMENT, event_id TEXT UNIQUE NOT NULL, type TEXT NOT NULL, task_id TEXT, attempt INTEGER, dispatch_id TEXT, payload TEXT NOT NULL, -- Canonical sorted JSON prev_hash TEXT NOT NULL, -- SHA-256 chain hash TEXT NOT NULL );

Never Trust Worker Self-Reports: Independent Verifier Path

A worker process reporting "SUCCESS" is never trusted by the controller. All outcome evaluations route through independent verifier modules that inspect the disk artifacts, check cryptographic hash deltas, and fail closed if anything raises.

# Verifier Contract (courier_core/verification.py) def run_verifier(resolve, task: TaskState, result: Event, home: Path) -> Verdict: if result.payload.get("outcome") != "success": return Verdict(accepted=False, reason="worker reported failure") verify_fn = resolve(task.adapter) if verify_fn is None: return Verdict(accepted=False, reason="no verifier registered; fail closed") return verify_fn(task, result, home)

Kirby Engine: Preventing EMFILE Storms & Thermal Throttle

Unbounded parallel subagents quickly exhaust operating system file descriptors (EMFILE) and consume all swap RAM. The Kirby engine dynamically monitors host health and coalesces wakeups so the host remains quiet, responsive, and bounded.

# Host Resource Governor (courier_runtime/continuity.py) def evaluate_admission(host_snapshot: dict) -> bool: if host_snapshot["ram_used_pct"] > 85 or host_snapshot["swap_used_pct"] > 40: return False # Park background workers, coalesce wakeups return True

One-Writer Principle: Eliminating Race Conditions by Construction

Two agents must never attempt to modify the same file or database concurrently. Courier enforces strict lease fencing on work packets. If a lease expires, the token invalidates instantly, preventing late outbox writes from corrupting data.

# Work Packet Queue (courier_core/work_packet.py) def get_admissible_packet(self, current_sha: str, host_safe: bool) -> Optional[WorkPacket]: currents = [p for p in self.packets.values() if p.state == PacketState.CURRENT] if currents: return currents[0] # one writer at a time in this sketch # Promote next only if host is safe

Fragen

Kurze Antworten. Wo etwas noch nicht belegt ist, steht das dabei.

Viele Agent-Bibliotheken ketten Prompts. Courier arbeitet am Ausführungsrahmen: Journal, fail-closed Prüfung und ein Schreiber pro Aufgabe. Anbieter bleiben austauschbare Adapter. Stand: Prototyp mit belegtem synthetischem Lauf (PR #361), keine fertige Plattform.

Courier focuses on durable execution control, not prompt chaining. Prototype; evidenced synthetic run in PR #361.

Ziel ist lokal zuerst: Journal und Prüfungen auf dem eigenen Rechner, ohne Tracking. Ein vollständig abgeschotteter Lauf ohne Netz ist noch nicht als fertiges Produkt nachgewiesen. Anbieter im Netz bleiben optionale Adapter und sind in Arbeit.

Local-first is the goal. A fully offline product run is not yet shown.

Im Prototyp trägt jede Aufgabe einen stabilen Effect-Key. Nach hartem Abbruch und Neustart zeigte der belegte Lauf (PR #361) 0 doppelte Aufgaben — mit synthetischem Test-Baustein, nicht mit einem echten Zahlungsanbieter.

Effect keys + evidenced 0 duplicates after hard kill/restart in PR #361 (synthetic adapter).

Der belegte Lauf ist ein Controller- und Worker-Prototyp (siehe Beleg, PR #361). Fertige Desktop-Pakete für Windows, macOS oder Linux sind geplant, nicht ausgeliefert.

Desktop packages are planned, not shipped. The evidenced run is the prototype in PR #361.
