Architecture Deep-Dive

Explore the four engineering pillars that provide mathematical guarantees for autonomous workflow execution.

Append-Only Journal: The Single Source of Truth

Unlike conventional agent runtimes that store state in memory or raw prompt context windows, Courier Symphony persists every state transition as a cryptographically linked event in courier.db. If power drops, replaying the sequence produces the exact identical projection.

-- Canonical Event Schema (courier_core/journal.py) CREATE TABLE events ( seq INTEGER PRIMARY KEY AUTOINCREMENT, event_id TEXT UNIQUE NOT NULL, type TEXT NOT NULL, task_id TEXT, attempt INTEGER, dispatch_id TEXT, payload TEXT NOT NULL, -- Canonical sorted JSON prev_hash TEXT NOT NULL, -- SHA-256 chain hash TEXT NOT NULL );

Never Trust Worker Self-Reports: Independent Verifier Path

A worker process reporting "SUCCESS" is never trusted by the controller. All outcome evaluations route through independent verifier modules that inspect the disk artifacts, check cryptographic hash deltas, and fail closed if anything raises.

# Verifier Contract (courier_core/verification.py) def run_verifier(resolve, task: TaskState, result: Event, home: Path) -> Verdict: if result.payload.get("outcome") != "success": return Verdict(accepted=False, reason="worker reported failure") verify_fn = resolve(task.adapter) if verify_fn is None: return Verdict(accepted=False, reason="no verifier registered; fail closed") return verify_fn(task, result, home)

Kirby Engine: Preventing EMFILE Storms & Thermal Throttle

Unbounded parallel subagents quickly exhaust operating system file descriptors (EMFILE) and consume all swap RAM. The Kirby engine dynamically monitors host health and coalesces wakeups so the host remains quiet, responsive, and bounded.

# Host Resource Governor (courier_runtime/continuity.py) def evaluate_admission(host_snapshot: dict) -> bool: if host_snapshot["ram_used_pct"] > 85 or host_snapshot["swap_used_pct"] > 40: return False # Park background workers, coalesce wakeups return True

One-Writer Principle: Eliminating Race Conditions by Construction

Two agents must never attempt to modify the same file or database concurrently. Courier enforces strict lease fencing on work packets. If a lease expires, the token invalidates instantly, preventing late outbox writes from corrupting data.

# Work Packet Queue (courier_core/work_packet.py) def get_admissible_packet(self, current_sha: str, host_safe: bool) -> Optional[WorkPacket]: currents = [p for p in self.packets.values() if p.state == PacketState.CURRENT] if currents: return currents[0] # Retain lock, single writer guaranteed # Promote next only if host is safe

Safety by Construction

Courier Symphony contains zero autonomous black-box behavior.

  • Zero autonomous spending: Model call budgets and external financial actions stop at human gates.
  • No secret exfiltration: API keys remain in local environment variables and are scrubbed from diagnostic packages.
  • Zero duplicate side effects: Idempotency keys protect external webhooks from repeated execution.
  • Fail-closed verification: Missing or raising verifier functions result in rejection; no default PASS.
